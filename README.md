# 📚 Sankara Web - Personal Reading Companion & AI Planner

Sankara adalah aplikasi web *fullstack* yang dirancang untuk membantu pengguna melacak progres membaca buku mereka sekaligus merencanakan kerangka tulisan/ide menggunakan fitur AI Planner. 

🚀 **Live Demo:** [https://sankara-web.vercel.app](https://sankara-web.vercel.app)

## ✨ Fitur Utama
- **Multi-User Authentication:** Sistem *login* dan registrasi aman menggunakan email & password.
- **Privasi Data RLS (Row Level Security):** Setiap pengguna memiliki rak bukunya sendiri yang terisolasi; pengguna tidak bisa melihat atau mengubah data milik orang lain.
- **Manajemen Perpustakaan (CRUD):** Tambah buku, pantau persentase halaman yang dibaca, edit status, dan hapus buku dari rak pribadi.
- **AI Outline Planner (Mock API):** Fitur generator kerangka ide otomatis berdasarkan topik yang diinputkan pengguna.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS, Vanilla JavaScript.
- **Backend:** Node.js, Express.js (berjalan sebagai *Serverless Function*).
- **Database & Auth:** Supabase (PostgreSQL, Backend-as-a-Service).
- **Deployment:** Vercel.
